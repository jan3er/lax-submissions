## Q1 design guidance (from the plan's author — follow unless you
have an argument, which then goes in the log)

- **Ambient-subset formulation.** Never glue abstract structures: fix
  an ambient `G : SimpleGraph (Fin n)` and work with boundaried
  subsets — `X : Set (Fin n)` (or `Finset`), marks `Fin r → Fin n`
  with values in `X`, set assignment `Fin s → Set (Fin n)`
  (semantically restricted to `X`). "Glue" is then literally `X ∪ Y`
  in the same ambient graph, under the hypotheses `X ∩ Y ⊆ marked`
  and no `G`-edges between `X \ Y` and `Y \ X`. No pushouts, no
  quotients, no isomorphism invariance — `T` and `F` are pure data,
  defined without reference to any graph, and every lemma is stated
  per-ambient. This is the trick that makes Q1 formalizable; treat
  deviations as plan changes.
- **Composition statement shape.** Give `X` and `Y` their own full
  mark tuples and state composition for *concatenated* marks plus an
  overlap pattern (the equality relation between mark positions);
  recover every other interface via the M5 mark lemmas. Do not try
  to build the "right" final interface directly into the induction —
  re-indexing inside the q-induction is the known pain point, and
  the mark lemmas exist to keep it out.
- **Set moves split cleanly**: in the union, a set choice `S`
  corresponds to the pair `(S ∩ X, S ∩ Y)` — this is where the
  no-cross-edges hypothesis does its work (atomic adjacency facts
  never cross), and why `T`'s set-move component needs no overlap
  data beyond the marks.
- MSO₁ atoms only (`adj`, `eq`, `mem`); `T 0` = the atomic diagram
  on marks (adjacency, equality, membership patterns — three finite
  tables).
- Loose everywhere: cardinality bounds on `T` are never needed, only
  finiteness; no normal forms; no computability of `F`.
